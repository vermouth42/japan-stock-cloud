# 日本株 デイ・スイング ルール仕様

TradingView（`tradingview/`）・MT5（`mt5/`）・Python（`python/`）は、すべてこの仕様で実装している。
パラメーターを変えるときは3つとも揃えること。

## 1. 指標の定義

| 指標 | 定義 |
|---|---|
| MA短・中・長 | 終値の単純移動平均。既定 5・25・75（日足なら日本株で定番の5日・25日・75日線） |
| 中期MAの傾き | `MA中 > MA中[5]`（5本前より上なら上向き） |
| ATR | トゥルーレンジの Wilder 平滑（14）。TradingView の `ta.atr` と同じ |
| RSI | Wilder 平滑（14）。TradingView の `ta.rsi` と同じ |
| 出来高倍率 | 当日出来高 ÷ 25日平均出来高（当日を含む）。`prices.csv` の「出来高倍率」と同じ |
| 引け位置 | (終値 − 安値) ÷ (高値 − 安値)。1 なら高値引け |
| 中期MA乖離率 | (終値 − MA中) ÷ MA中 × 100 |

※ `prices.csv` の `ATR14` 列は TR の単純平均で、ここでの ATR（Wilder）とは少しずれる。

## 2. トレンド判定

- **上昇トレンド**: 終値 > MA長、MA中 > MA長、MA中が上向き
- **下降トレンド**: 上の逆
- **パーフェクトオーダー（PO）**: MA短 > MA中 > MA長

## 3. スイング（日足）のシグナル

判定は**終値**。上から順に、最初に当てはまったものを採用する。

| 記号 | 名前 | 条件 |
|---|---|---|
| BO | ブレイクアウト買い | 終値が前日までの20日高値を上抜け／出来高倍率 ≥ 1.5／引け位置 ≥ 0.6／終値 > MA中／MA中が下向きでない／RSI ≤ 80／乖離率 ≤ +15% |
| PB | 押し目買い | 上昇トレンド／直近3本の安値が MA中 + 0.5ATR 以内まで押した／終値 > MA中／終値 > 前日高値／陽線／40 ≤ RSI ≤ 65 |
| BD | ブレイクダウン売り | BO の逆（20日安値を割る、引け位置 ≤ 0.4、RSI ≥ 20、乖離率 ≥ −15%） |
| RS | 戻り売り | PB の逆（下降トレンド、MA中 − 0.5ATR まで戻した、終値 < 前日安値、陰線、35 ≤ RSI ≤ 60） |

**考え方**: 上昇トレンドの銘柄だけを、「出来高を伴う高値更新」か「25日線までの押しからの反転」で買う。
上ヒゲの長い高値更新（引け位置が低い）と、25日線から離れすぎた高値更新（乖離 +15% 超）は追いかけない。

## 4. デイトレ（分足）のシグナル

| 記号 | 名前 | 条件 |
|---|---|---|
| ORB | オープニングレンジブレイク | 寄り付きから15分（OR）の高値を終値で上抜け／終値 > VWAP／出来高 ≥ 20本平均 × 1.5／寄りのギャップ ≤ +5%／日足トレンドが上 |
| VWAP | VWAP反発 | 終値 > VWAP／安値が VWAP + 0.3ATR まで押した／陽線／VWAP が3本前より上／終値 > OR中値／日足トレンドが上 |

- 売りはそれぞれの逆。
- 新規エントリーは **9:05〜11:15、12:30〜14:30（JST）** だけ。寄り直後・昼休み前・大引け前は避ける。
- 日足トレンド = 前日終値が日足の25日線より上（買い）／下（売り）。
- ギャップが +5% を超える日は寄り天になりやすいので、ORB の買いはしない。

## 5. フィルター（ストラテジー・任意）

| フィルター | 内容 | 既定 |
|---|---|---|
| 地合い | 日経平均（`TVC:NI225`）の前日終値が75日線より上なら買いのみ、下なら売りのみ | スイングはON、デイはOFF |
| ファンダメンタルズ | 7項目の判定（下表）で合格ライン以上の銘柄だけ買う | スイングはON |
| 決算 | 次回決算予定日の3日前から新規エントリーしない | ON（リアルタイムのみ有効） |

### ファンダメンタルズの7項目（TradingView 版）

| 項目 | 計算 | 合格 |
|---|---|---|
| ROE | 当期純利益（直近12か月）÷ 自己資本（直近四半期） | ≥ 8%（伊藤レポートの目安） |
| 営業利益率 | 営業利益 ÷ 売上高（直近12か月） | ≥ 10% |
| 売上高成長率 | 通期売上高の前期比 | ≥ 5% |
| EPS成長率 | 通期EPSの前期比 | ≥ 0% |
| 自己資本比率 | 自己資本 ÷ 総資産（直近四半期） | ≥ 40% |
| FCF | フリーキャッシュフロー（直近12か月） | > 0 |
| PER | 株価 ÷ EPS（直近12か月） | 黒字かつ ≤ 25倍 |

- 合格ラインは既定で 7項目中4。データが取れない項目は採点から外し、合格ラインも項目数に比例して下げる（例: 5項目しか取れなければ 3/5 で合格）。
- データがまったく取れない銘柄（ETF・指数など）は判定しない（フィルターを通す）。
- 成長率は「チャートの表示期間内で決算期が切り替わった」ときにしか計算できない。分足で表示期間が短いと「—」になる。
- 赤字のバイオ株などは不合格になりやすい。テーマ株を狙うときはフィルターを外すこと。

## 6. 決済（ストラテジー・Python バックテスト共通）

| 項目 | スイング | デイ |
|---|---|---|
| エントリー | シグナル足の翌足始値（成行） | 同左 |
| 初期損切り | シグナル終値 ∓ 2.0×ATR | ∓ 1.5×ATR（分足ATR） |
| 第1利確 | 2.0R で建玉の50%（単元未満は切り捨て） | 1.5R で50% |
| 第1利確の後 | 残りのストップを建値以上に引き上げ | 同左 |
| トレーリング | エントリー後の最高値 − 3.0×ATR | − 2.0×ATR |
| 終値での手仕舞い | 終値 < 25日線 − 1.0ATR、または保有30日 | 終値 < VWAP |
| 強制決済 | 決算前日（任意・リアルタイムのみ） | 15:20（その足の終値で約定。持ち越さない） |

- 1R = 初期損切りまでの値幅（= 2.0×ATR）。
- ストップは有利な方向にしか動かない。値は毎日の終値時点で更新し、翌日のザラ場で約定する。
- 窓を空けてストップを越えたら始値で約定する。同じ日に損切りと利確の両方に届いたら、損切りが先とみなす（保守的）。
- 25日線割れに 1.0ATR の余裕を持たせているのは、押し目買いがもともと25日線の近くで入るため。余裕がないとダマシで振り落とされる（検証で、この手仕舞いが決済理由の過半を占めていた）。

## 7. 資金管理

- 数量 = min(資金 × 1% ÷ 1R, 資金 × 50% ÷ 株価) を **100株単位に切り捨て**。100株に満たなければ見送り。
- 初期資金 300万円、手数料 0（SBI・楽天などの国内株の売買手数料無料プランを想定）、スリッページ 1ティック。
- 信用売りは既定でOFF。空売り規制（前日終値から10%以上下落した銘柄のアップティックルール）、貸株料・逆日歩はバックテストに含まれない。

## 8. アラート（Webhook）の JSON

ストラテジーは注文ごとに `alert_message` を出す。アラート作成画面の「メッセージ」欄を
`{{strategy.order.alert_message}}` だけにし、Webhook URL を指定する（Webhook は TradingView の有料プランが必要）。

```json
{"bot":"JP-EA","event":"entry","mode":"swing","side":"long","symbol":"7203","exchange":"TSE",
 "time":"2026-10-29 15:30","setup":"PB","qty":200,"price":2500,"sl":2400,"tp":2700}

{"bot":"JP-EA","event":"exit","mode":"swing","side":"long","symbol":"7203","exchange":"TSE",
 "time":"2026-11-05 15:30","reason":"tp1_or_stop","qty":100,"close_all":false}
```

| reason | 意味 | qty |
|---|---|---|
| `tp1_or_stop` | 第1利確の注文（利確か損切りで約定） | 決済株数 |
| `stop` | 損切り・トレーリング・建値ストップ | 0（= 残り全部） |
| `ma` / `time` / `earnings` | 25日線割れ／期間満了／決算前 | 0 |
| `vwap` / `eod` | VWAP割れ／引け前の強制決済（デイ） | 0 |

**受け手（発注ブリッジ）の注意**: 損切りに届くと `tp1_or_stop` と `stop` が同時に届く。
「qty 株を決済。ただし保有株数を上限にする」「close_all なら全部決済」と処理すれば、届く順番に関係なく正しく決済できる。

## 9. 実装ごとの違い

| | TradingView | MT5 | Python |
|---|---|---|---|
| スイングのシグナル | ○ | ○ | ○ |
| デイのシグナル | ○ | ○ | — |
| 地合いフィルター | ○ | — | — |
| ファンダメンタルズ | ○ | — | — |
| 自動売買 | ストラテジー＋Webhook | （インジケーターのみ） | バックテストのみ |
| 時刻 | 東京時間で判定 | サーバー時刻→日本時間に自動換算（手動指定も可） | 日足のみ |
| 出来高 | 実出来高 | 実出来高（なければティック出来高） | 実出来高 |

MT5 と Python は、`prices.csv` の全100銘柄・15,907本でシグナルが一致することを確認済み（MT5 のコードを C++ に移して実行して比較）。

## 10. 検証結果と注意（2026-10-29 時点）

`python python/backtest.py`（買いのみ、既定パラメーター、100銘柄、2026-03〜2026-10）:

| | 回数 | 勝率 | 平均 | PF |
|---|---:|---:|---:|---:|
| 全体 | 152 | 31.6% | +0.08R | 1.18 |
| BO | 25 | 44.0% | +0.10R | 1.23 |
| PB | 127 | 29.1% | +0.08R | 1.17 |
| 決済済みのみ | 139 | 28.8% | +0.02R | 1.05 |

- `prices.csv` は約240日分しかなく、75日線の計算に75本使うため、実質の検証期間は約4か月。**この結果だけで優位性があるとは言えない**。
- 同じ期間の売り（BD・RS）は大きく負け越した（PF 0.42）。上昇相場だったことを考えても、売りは既定でOFFのままにしておくのがよい。
- 本番の前に、TradingView のストラテジーテスターで10年以上の日足と複数の地合い（2018年末・2020年3月・2024年8月の急落など）を確認すること。
- 勝率は低く、利益は少数の大勝ちで出る形。最大連敗は16回。1トレードの許容損失を資金の1%以下にしておけば、16連敗でも約15%のドローダウンで済む。
