## 実行方法

認証済みの読み取り担当が、次の範囲をUNFORMATTED_VALUEで取得する。APIキーやトークンはJSONに含めない。

| bundleキー | 本番の範囲 |
|---|---|
| top10 | 実戦候補TOP10!A1:Q11 |
| sbi | SBI連動_v77!A3:O13 |
| events | イベント管理!A1:I100 |
| captured_at | 実際の読み取り開始時刻（タイムゾーン付き） |
| spreadsheet_timezone | Asia/Tokyo |
| receipts | 銘柄ごとの確認記録。未確認時は空オブジェクト |

株価データ取込!A3:R4502、GitHub status.jsonとprices.csvを同じ検証時点で別途取得する。

```sh
python -m astra.sheet_bridge --bundle private_bundle.json --status status.json \
  --prices prices.csv --sheet-rows private_sheet_rows.json
```

終了コードは常に2。`go_allowed` は常にfalse。未知の入力形式は停止する。結果の `offline_checks_passed` は本番運用許可を意味しない。

## 確認記録の受け入れ仕様

`receipts[銘柄コード]` は `RECEIPT_KEYS` にある全項目のみを受け入れる。rank_checked_at、sbi_checked_at、event_checked_atは本人の確認時刻。SBI日時はシートN列と1ミリ秒以内で一致すること。events_clear_throughは今日から次の3JPX営業日までを調査済みである必要がある。event_evidenceには調査した公式の出典と対象範囲を残す。

指紋は機密の署名ではなく取り違え防止用。信頼できる確認処理からの保存と改変検出の設計・配備が必要で、手入力で指紋を作れたことは確認済みの証明にならない。
