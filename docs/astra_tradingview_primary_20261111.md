# TradingView主軸・SBI手動注文への実装変更

## 最新要件

価格・VWAP・テクニカルの主軸はTradingView。SBIは注文先で、毎回のSBI価格入力を要求しない。勤務中の操作は注文のみが目標。旧手動ゲートは移行完了まで残し、既存の停止条件を外すだけで自動GOにしない。

## 実装

`tradingview/CloudLite_TV_Monitor_v6.pine` はTradingView内で完結する技術観測版。日付と価格の毎回入力を廃止し、チャートの確定足・当日VWAP・出来高継続・過去高値・上ヒゲ・ギャップを評価する。MA/EMA、RSI、MACD、ATR、BB、OBVもデータウィンドウに表示。すべてを一律の買い条件に混ぜない。

各種類の通知を15分間隔・1日3回までに制限。1/5分足限定、寄付きデータがない場合と古い確定足では通知しない。初期通知OFF。旧Pine・本番Sheet・注文機能を置換しない。

この版はA/A+・イベント・板・口座情報未連携なので、通知は「技術観測・GO禁止」。VWAP下抜けを実保有の利確・損切りと断定しない。Pineの模擬建玉をSBI実保有と扱わない。100銘柄の日足監視と、個別チャートの分足通知範囲を区別する。

## 公式接続調査（2026-11-11）

- [TradingView公式MCP](https://www.tradingview.com/mcp/docs) はEssential以上の本契約向け。OAuth接続。1回最大50銘柄の情報取得、指標、経済・決算予定、ウォッチリスト操作、単純価格アラート操作を案内している。実アカウントのMCPは未接続。日本株データの配信遅延・権限は実応答で確認が必要。
- 同公式MCPのアラート作成は単純価格条件のみ。Pine/複合条件・Webhook作成は未対応。作成応答startingは稼働証明でなく、取得し直してactiveを確認する。
- [利用規約27条](https://www.tradingview.com/policies/) は個人の要求に答え、人が読める結果を表示する限定的なAI処理を認める。一方、MCPを恒常的な蓄積用データ配信や自動注文に転用しない。公式MCP接続だけで独立した無人売買判断基盤の利用許諾が確定したとは扱わない。
- [プラン比較](https://www.tradingview.com/pricing/) ではEssentialは価格20・技術20アラート。100銘柄すべての個別技術アラートを無制限に作れる前提を置かない。増額や契約変更はしない。
- [Pine Seeds公式](https://github.com/tradingview-pine-seeds/docs/blob/main/README.md) は新規リポジトリ作成を停止中。GitHubのA/A+を任意HTTPでPineに読み込ませる方式は採用しない。
- [公式アラート仕様](https://www.tradingview.com/pine-script-docs/concepts/alerts/) に合わせ、通知はTradingViewサーバー上の作成時コピーで動く。チャート入力変更だけでは既存アラートへ反映されない。
